# Project Background 
An end-to-end data project involving Excel-based data cleaning, sorting, and organization, with Power BI dashboards used to visualize key metrics, identify trends, and communicate insights effectively. This project explores how fast food consumption influences various health and lifestyle indicators. It contains synthetic yet realistic data representing individuals’ eating habits, physical activity, sleep patterns, and overall health outcomes.

# Overview of Findings 


## Tools Used
- Microsoft Excel
- Microsoft Word
- Microsoft Power BI
- Tables
- Filters
- Sorting techniques
- Graphs and visual elements

## What This Project Shows
- Cleaning and preparing raw data for analysis
- Sorting and managing large datasets efficiently
- Organizing structured data for meaningful analysis
- Creating clear visualizations to highlight trends and insights
